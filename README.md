# Minesweeper

_Title screen image generated by ChatGPT_

## Setup

1. **Clone this repo**. Then, from the project root, create a virtual environment:
```
python -m venv .venv
```

2. Activate the environment.

Mac / Linux:
```
source .venv/bin/activate
```

Windows:
```
.venv/Scripts/activate
```

3. Install dependencies:
```
pip install -r requirements.txt
```

## Running

Make sure your virtual environment is activated as in the setup section. Then, from the project root:
```
python src/main.py
```

## How to play

Left click a cell to reveal it. Right click to flag a cell as dangerous.

## Project layout

- `src/`: Game code
- `assets/`: Other files used by the game
